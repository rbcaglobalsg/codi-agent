🚀 퀵스타트

5분 안에 코디를 설치하고 실행합니다.

1저장소 클론 
git clone https://github.com/rbcaglobalsg/codi-agent.git
cd codi-agent
2의존성 설치 
pip install -e .

Python 3.11 이상 필요.

3LLM API 키 설정

지원 프로바이더 중 하나를 선택해 API 키를 발급받습니다.

# OpenRouter (추천 — 다중 모델)
export OPENROUTER_API_KEY=sk-or-v1-xxxxx

# OpenAI
export OPENAI_API_KEY=sk-xxxxx

# Anthropic
export ANTHROPIC_API_KEY=sk-ant-xxxxx
추천: OpenRouter는 하나의 키로 여러 모델(claude, gpt, deepseek)을 모두 사용할 수 있습니다.
4설정 파일 생성 
# config.yaml 생성
provider: openrouter
model: anthropic/claude-sonnet-4
# 또는: openai/gpt-4o, deepseek/deepseek-chat
5실행 
# 터미널에서
codi

# 카카오톡/텔레그램 연동 시
codi gateway start

첫 대화를 시작하세요: "안녕? 뭐 할 수 있어?"
