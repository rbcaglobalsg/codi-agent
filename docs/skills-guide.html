⚡ 스킬 만들기

코디는 대화하며 자동으로 스킬을 학습합니다. 직접 스킬을 만들 수도 있습니다.

스킬이란?

스킬은 재사용 가능한 절차를 담은 마크다운 파일입니다. 코디가 문제를 해결하면 자동으로 스킬을 생성하고, 다음에 비슷한 문제를 만나면 즉시 스킬을 로드해서 해결합니다.

스킬 만들기

# skills/my-skill/SKILL.md 생성
---
name: my-skill
description: "스킬 설명 — 코디가 언제 이 스킬을 사용할지 알 수 있게"
version: 1.0
language: ko
tags: [tag1, tag2]
---

# 스킬 제목

## 트리거
이 스킬이 언제 실행되어야 하는지 설명합니다.

## 절차

### 1단계: ...
구체적인 단계를 적습니다.

### 2단계: ...
코디가 이 단계를 그대로 따라 실행합니다.

## 주의사항
- 피해야 할 것
- 확인해야 할 것

스킬 공유하기

스킬은 마크다운 파일이므로 GitHub, 블로그, 카카오톡으로 공유할 수 있습니다. 코디 클라우드(준비 중)에서는 스킬 마켓플레이스를 통해 판매도 가능합니다.

자동 학습

코디와 대화하다 보면, 코디가 복잡한 문제를 해결한 후 "이 작업을 스킬로 저장할까요?"라고 물어봅니다. 승인하면 자동으로 SKILL.md가 생성되어 다음에 재사용됩니다.
