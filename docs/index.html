왜 코디인가

기존 챗봇과 다릅니다. 코디는 대화할수록 학습하고, 당신만의 워크플로우를 기억합니다.

🧠

대화할수록 진화

해결한 문제를 스킬로 자동 저장. 같은 질문은 두 번 다시 처음부터 시작하지 않습니다. 대화가 쌓일수록 당신에게 최적화됩니다.

🔑

자기 API 키, 자기 모델

OpenRouter, OpenAI, Anthropic, DeepSeek, 로컬 모델 — 어떤 LLM이든 당신의 API 키로 연결. 특정 회사에 종속되지 않습니다.

⚡

개발자 특화 스킬

코드 리뷰, 배포 자동화, 디버깅, TDD, CI/CD — 처음부터 개발자 워크플로우에 최적화. 새 스킬도 쉽게 추가.

🇰🇷

완전 한국어

시스템 프롬프트, 에러 메시지, 도움말 — 모두 한국어. 한국 개발 환경에 맞춘 에이전트. 영어가 필요하지 않습니다.

💬

어디서나 대화

터미널, 브라우저, 카카오톡, 텔레그램, 디스코드, 슬랙 — 같은 에이전트가 모든 플랫폼에서 작동. 어디서든 이어서 작업.

🔄

자가 학습 시스템

복잡한 문제를 해결하면 자동으로 스킬 문서 생성. 다음에 같은 문제를 만나면 즉시 해결. 팀원과 공유도 가능.

어떻게 성장하는가

1

대화로 시작

"이 코드 리뷰해줘", "배포 자동화 만들어줘", "이 에러 잡아줘" — 자연어로 명령합니다. 코디가 즉시 실행합니다.

2

해결하며 학습

문제를 해결하는 과정에서 코디가 패턴을 파악합니다. 어떤 접근법이 효과적이었는지, 어떤 실수를 피했는지 기억합니다.

3

스킬로 축적

해결한 문제가 재사용 가능한 스킬로 자동 저장됩니다. 다음에 비슷한 문제를 만나면, 코디가 이미 답을 알고 있습니다.

4

진화

대화가 쌓일수록 코디는 당신에게 최적화됩니다. 당신의 코드 스타일, 선호하는 도구, 프로젝트 구조를 학습하고 점점 더 빨라집니다.
