# 한국어 코드 리뷰

## 트리거
코드 리뷰 요청, PR 리뷰, 코드 품질 점검, "리뷰해줘", "코드 확인해줘"

## 절차

### 1. 구조 파악
- 전체 파일 구조 읽기
- 의존성 관계 파악
- 변경 범위 확인 (git diff)

### 2. 보안 점검
- 하드코딩된 시크릿/키/API 키
- SQL 인젝션 위험
- XSS/CSRF 취약점
- 인증/인가 누락
- 파일 경로 조작

### 3. 성능 점검
- N+1 쿼리
- 불필요한 반복문
- 메모리 누수
- 동기/비동기 적절성

### 4. 가독성 점검
- 함수 길이 (50줄 이하 권장)
- 변수명 의미성
- 주석 필요 지점
- 중복 코드

### 5. 한국 특화
- 한국 시간대(Asia/Seoul) 고려
- 한국어 인코딩(UTF-8) 확인
- 한국 서비스 API (네이버/카카오/토스) 사용 시 공식 문서 준수

## 리포트 형식
```
## 코드 리뷰 결과

### 🔴 심각 (수정 필수)
- [파일:라인] 문제 설명 + 수정 제안

### 🟡 권장 (개선 권장)
- [파일:라인] 개선 제안

### 🟢 좋음
- 잘 작성된 부분 언급

### 📊 종합 평가
- 보안: X/10
- 성능: X/10
- 가독성: X/10
```
